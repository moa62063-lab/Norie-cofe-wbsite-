# NOIRÉ — Café & Artisanal Roastery

A modern, responsive landing page for **NOIRÉ**, an artisanal coffee roastery and literary salon concept inspired by 1920s Parisian cafés. The project blends specialty Nordic roasting discipline with timeless European hospitality.

> **Note**: This website is a portfolio concept project created to demonstrate high-fidelity translation from UI design to production-ready frontend code.

---

## ✨ Features & Highlights

- **Visual Fidelity**: Faithful recreation of the original UI layout, custom typography hierarchy, warm neutral color scheme, and editorial card structures.
- **Section Architecture**:
  - **Header & Navigation**: Brand mark, anchor navigation links, and full mobile drawer.
  - **Hero Section**: Single-origin badge, stats overview, dual CTAs, and signature extraction card.
  - **Chapter I — The Roastery Journal**: Brand story narrative, master roaster credentials, and archival photo frame.
  - **The Degustation (Our Menu)**: Two-column menu covering hot & cold coffee, teas, and viennoiserie with pricing and seasonal upgrades.
  - **Our Philosophy (Why NOIRÉ?)**: 4 pillar cards detailing direct trade sourcing, salon space, heirloom ingredients, and heritage.
  - **Visual Journal**: Archival 3-plate photographic gallery.
  - **Praise & Reflections**: Editorial guest quotes and reviews.
  - **Salon & Atelier (Come Find Us)**: Address, hours of service, contact links, and interactive map card for Paris 6th Arrondissement.
  - **Footer**: Navigation links, operating hours, and archival batch metadata.
- **Responsive Layout**: Designed for optimal viewing across mobile, tablet, and desktop screens.
- **Performance & Modern Stack**: Zero bloat, instant Vite build and HMR.

---

## 🛠️ Tech Stack & Workflow

- **Framework**: [React](https://react.dev/) (v18)
- **Bundler & Dev Server**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Typography**: Google Fonts (*Cormorant Garamond* & *Plus Jakarta Sans*)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Design & Workflow**: Designed in **Figma** and developed using **Google Antigravity** as an AI pair programming assistant to facilitate rapid implementation, asset generation, and visual verification.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- `npm` or equivalent package manager

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/moa62063-lab/Norie-cofe-wbsite-.git
   cd Norie-cofe-wbsite-
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the local development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

To build the project for production:
```bash
npm run build
```

To preview the production build locally:
```bash
npm run preview
```
